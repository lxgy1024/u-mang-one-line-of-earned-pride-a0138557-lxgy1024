A make.fun bounty entry: one line, 1 to 240 characters, giving the judge a quiet, earned moment of pride for someone in a scene.

## The entry

> He let go of the saddle, and for six wobbly metres his daughter rode alone while he ran behind her, cheering, out of breath.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
